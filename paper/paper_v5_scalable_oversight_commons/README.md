# Evaluating Oversight in Sequential Commons

Current draft: 4 October 2026. The prior version is preserved in `archive/pre_validation_20260913/`.

## Build

Run from this folder:

```bash
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

Compilation uses paper-local figures and tables. It does not require the raw simulation archive.

## Current evidence

- The interaction diagram is native TikZ in `main.tex`.
- `figures/fig08_reviewer_decisions.pdf` is the main fresh-context
  inspection-budget result; `data/analysis/` contains its curated counts.
- `figures/matched_mechanisms_slow.pdf` shows frozen-policy controls under the existing slow-regrowth setting.
- `figures/generator_validation.pdf` shows search performance on unseen episodes with parent-context uncertainty.
- `figures/fig03_actor_factors.pdf` keeps generation and overseer settings separate in the appendix.
- `tables/table_validation_results.tex` gives matched unsafe rates in both base and slow regrowth.
- The original Stage A descriptive table and model-template control results appear directly in the manuscript.
- The coupled-local replay is post-hoc and reproducible from the included
  confirmation archive. It is not a new independent confirmation cohort.

Old gap, winner, trace, and model plots remain available for provenance, but are not the current main evidence. The older `plot_scalable_oversight_paper_v5` script generates those historical assets; it is not the new paper build pipeline.

## Rebuild analysis and figures

From the repository root, using existing completed blocks:

```bash
python -m experiments.analyze_harvest_validation
cp notes/research_review/completed_checks/slow_regrowth/matched_mechanisms.pdf paper/paper_v5_scalable_oversight_commons/figures/matched_mechanisms_slow.pdf
cp notes/research_review/completed_checks/generator_validation.pdf paper/paper_v5_scalable_oversight_commons/figures/generator_validation.pdf
cp notes/research_review/completed_checks/table_validation_results.tex paper/paper_v5_scalable_oversight_commons/tables/table_validation_results.tex
```

The analyzer exports vector PDF/SVG and 300-dpi PNG. The factor-separated appendix plot comes from `notes/research_review/evidence/actor_overseer_separated.pdf`, generated by `experiments.audit_research_evidence` from Stage A logs.

The current main figure can be regenerated on a clean checkout from the
small curated data package, without the ignored raw simulation directory:

```bash
python -m experiments.plot_reviewer_decisions \
  --input-dir paper/paper_v5_scalable_oversight_commons/data \
  --output-dir paper/paper_v5_scalable_oversight_commons/figures
```

See `data/README.md` for the export command, the bounded full confirmation
archive, source checksums, and the historical tables included in this release.

For source requirements, run counts, actual timings, and the next research question, see [paper closeout](../../notes/research_review/PAPER_CLOSEOUT_20260924.md). The checked-in archive allows the current confirmation analysis to be audited on a clean clone; full historical reruns and fresh independent reproduction still require the documented software and compute environment.
